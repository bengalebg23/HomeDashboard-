# Home Dashboard

Family home dashboard: launches Meal Rota, Chores, Money Flow and Google Calendar, with a glance at today's meals, chore status, a shared to-do list and an embedded calendar.

Live: https://bengalebg23.github.io/HomeDashboard-/

Single-file PWA (`index.html` + `sw.js`), no build step. Handoff notes are at the top of `index.html`.
Every release bumps `APP_VERSION` in `index.html` and `CACHE_VERSION` in `sw.js`.
